
# Shortest Paths and Minimum Spanning Trees

Introduction to Algorithm design and anaylsis project:

Implemented Dijkstra’s shortest path algorithm and Prim’s minimum spanning tree algorithm for graphs represented using adjacency lists. Compared two implementations of the fringe data structure, one using a binary heap and the other using a linked list. Built an interactive interface that animates each major iteration and lets users add edges one at a time to update the resulting trees.
